# Chronopotentiometry Example Data

This folder contains an anonymized CH Instruments chronopotentiometry text
export from a cycling experiment. The file is useful for trying eCAT CP loading,
plotting, cycle detection, cycle summaries, and potential-vs-time workflows.

The packaged file is:

- `CP-100-cycles_MeCN_500mVs_100mMTBAPF6_gcWE_ptCE_AgAgbf4-5mM.txt`

This is public tutorial data for exercising the CP parts of eCAT. It has been
renamed and lightly curated for portability. It is not a curated mechanistic
benchmark.
