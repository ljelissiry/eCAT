# Fe/PhOH DPV Example Data

This folder contains two CH Instruments differential pulse voltammetry (DPV)
text exports from the Fe-tpyPY2Me / Fc example set:

- `MeCN_Ar_0.1MTBAPF6_3mMFc_1mMFe-tpyPY2Me_DPV_-0.7_to_-1.2V.txt`
- `MeCN_CO2_0.1MTBAPF6_3mMFc_1mMFe-tpyPY2Me_DPV_-0.7_to_-1.2V.txt`

They are intended for the DPV quickstart notebook. The pair keeps the pulse
settings and scan window fixed while changing the gas condition.
