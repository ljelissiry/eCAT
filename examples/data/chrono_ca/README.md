# Chronoamperometry / CPE Example Data

This folder contains anonymized CH Instruments chronoamperometry text exports
from a constant-potential electrolysis series. The files are useful for trying
eCAT CA loading, plotting, current integration, and charge-based workflows.

The packaged set uses the Fe-2imm / CO2 / 0.1 M KCl series:

- -0.95 V vs Ag/AgCl, 60 min CPE, 0.6516 C
- -1.0 V vs Ag/AgCl, 60 min CPE, 1.274 C
- -1.1 V vs Ag/AgCl, 60 min CPE, 2.192 C
- -1.2 V vs Ag/AgCl, 60 min CPE, 2.565 C

These are public tutorial files for exercising the CA/CPE parts of eCAT. They
have been renamed and lightly curated for portability. They are not a curated
mechanistic benchmark.
