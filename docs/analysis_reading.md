# Analysis methods and further reading

These references explain method assumptions and interpretation. They do not establish that eCAT implements every method in each paper. See the [implemented equations and parameter definitions](analysis_equations.md) for formulas, units, controls and limitations.

| Function | What to read and why |
|---|---|
| `fowa` | Start with the catalytic mechanism and its appropriate FOWA expression, then choose the foot region and inspect the fit diagnostics. Wang and Johnson discuss the role of Ecat/2 and interpretation of multielectron waves. A catalytic half-wave potential is not automatically the non-catalytic redox midpoint; a fitted line alone does not establish the mechanism. [FOWA](https://doi.org/10.1021/ja303560c), [ECAT2](https://doi.org/10.1021/acscatal.9b00850), [CAT](https://doi.org/10.1021/ic500658x) |
| `tafel_analysis` | These references concern molecular catalytic TOF–overpotential relationships. Do not interpret this function as a general heterogeneous-electrode Tafel-slope fitting routine. [FOWA](https://doi.org/10.1021/ja303560c), [CAT](https://doi.org/10.1021/ic500658x) |
| `plateau_current` | Check that the plateau represents the applicable kinetic regime before converting current to a rate. Transport, depletion and deactivation can change the observed plateau. [CAT](https://doi.org/10.1021/ic500658x), [FOWA](https://doi.org/10.1021/ja303560c) |
| `nicholson_analysis` | The default ψ conversion interpolates Agarwal Table 4; psi source=lavagnini selects the Lavagnini approximation. Nicholson supplies the underlying model. Use paired peak separation only within the model and calibrated domain; diffusion coefficients, temperature and electron count are inputs, not inferred proof of the mechanism. [NICH](https://doi.org/10.1021/ac60230a016), [AGARWAL](https://doi.org/10.1021/acselectrochem.5c00214), [LAVAGNINI](https://doi.org/10.1002/elan.200302851), [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `trumpet_analysis` | Laviron supplies background for surface-confined kinetics, used separately in reversibility_analysis. The standalone trumpet_analysis implements the diffusion-dependent formulas printed here; this citation does not establish the provenance of its fixed factor 2 and constant 0.78. Report branch trends descriptively unless the selected kinetic model is independently justified. [LAV](https://doi.org/10.1016/S0022-0728(79)80075-3), [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `surface_coverage_analysis` | Read for the surface-confined model and its assumptions. The eCAT charge and scan-rate estimates require valid baseline subtraction and a justified electron count. [LAV](https://doi.org/10.1016/S0022-0728(79)80075-3) |
| `reversibility_analysis` | The bulk model combines Matsuda–Ayabe regions with the same selectable Nicholson conversion as nicholson_analysis (Agarwal by default; Lavagnini optional). Surface analysis uses the Laviron framework. Chemical recovery is assessed separately through current ratios; its numerical acceptance tolerances are eCAT settings, not universal literature constants. [MATSUDA](https://doi.org/10.1002/bbpc.19550590605), [NICH](https://doi.org/10.1021/ac60230a016), [AGARWAL](https://doi.org/10.1021/acselectrochem.5c00214), [LAVAGNINI](https://doi.org/10.1002/elan.200302851), [LAV](https://doi.org/10.1016/S0022-0728(79)80075-3), [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `sevcik_analysis` | Read for diffusion-controlled peak-current scaling with the square root of scan rate. Linearity alone does not establish all Randles–Ševčík assumptions. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `fit_peak_current` | Use the electrochemical model to select the x transform; a generic power fit is descriptive unless its physical assumptions are justified. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `fit_peak_potential` | Peak-shift trends can be reported descriptively. Laviron kinetic interpretation specifically assumes the relevant diffusionless model. [CV](https://doi.org/10.1021/acs.jchemed.7b00361), [LAV](https://doi.org/10.1016/S0022-0728(79)80075-3) |
| `fit_rate` | Use for interpreting catalytic rate quantities supplied to this fitter. The paper does not validate every generic regression model available in eCAT. [CAT](https://doi.org/10.1021/ic500658x) |
| `cv.peak_potential` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `cv.peak_current` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `cv.peak_width` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `cv.half_peak_potential` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `cv.peak_info` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
| `cv.half_wave_potential` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |

| `normalize` | Background on peak selection, scan-rate dependence and interpretation. eCAT’s baseline, smoothing and normalization options remain implementation choices; record them with the result. [CV](https://doi.org/10.1021/acs.jchemed.7b00361) |
